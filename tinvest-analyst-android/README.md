# T-Invest Analyst — приложение для анализа рынка и консультативных выводов

Отдельное Android-приложение (собственный `applicationId` — `com.tinvestanalyst`),
ставится рядом с торговым ботом и работает независимо от него: общего кода,
общих настроек и общего токена у них нет.

## Ключевое отличие от бота

Приложение **физически не может совершить сделку**: в его API-клиенте нет ни
одного метода выставления заявок, только чтение рыночных данных. Поэтому для
него достаточно токена **только на чтение** — даже если вставить токен с
полным доступом, торговать приложение не станет.

## Что делает

- **Список наблюдения** — бумаги ищутся по тикеру или названию (SBER, GAZP,
  LKOH), FIGI подставляется автоматически, вручную ничего вводить не нужно.
- **Котировки в реальном времени** — пока экран открыт, цены обновляются раз
  в 15 секунд одним пакетным запросом на весь список (это бережёт лимиты API).
- **Свечной график** с наложенными SMA(9) и SMA(21) и гистограммой объёма,
  нарисованный на Canvas.
- **Сводная рекомендация** по шкале «активно покупать — покупать — держать —
  продавать — активно продавать» с процентом уверенности.
- **Разбор рекомендации по факторам** — главное: виден не только вывод, но и
  как он получен.

## Как считается рекомендация

Шесть независимых факторов, каждый со своим весом, дают оценку от `-вес` до
`+вес`; сумма нормируется и переводится в вердикт:

| Фактор | Вес | Что измеряет |
|---|---|---|
| Тренд SMA(9/21) | ±2 | направление тренда и момент пересечения средних |
| Долгосрочный тренд SMA(50) | ±1 | положение цены относительно длинной средней |
| RSI(14) | ±2 | перекупленность/перепроданность |
| MACD(12/26/9) | ±2 | смену импульса и её силу |
| Полосы Боллинджера(20, 2σ) | ±1 | статистическую растянутость движения |
| Объём | ±1 | подтверждён ли ход деньгами |

Плюс ATR(14) — волатильность и ориентиры стопа (1.5 ATR) и цели (2.5 ATR),
и разбор стакана заявок (перевес покупателей или продавцов).

Каждый фактор показывает и свои числа, и словесную трактовку — вывод всегда
можно перепроверить руками.

## Ограничения, которые важно понимать

- Это **технический анализ по ценам и объёмам**. Он не знает отчётности
  эмитента, новостей, дивидендов, санкционных рисков и вашего горизонта.
- Это **не индивидуальная инвестиционная рекомендация**: приложение не знает
  ни целей, ни риск-профиля инвестора и никем не лицензировано как советник.
- Индикаторы запаздывают по своей природе: на резких новостных движениях они
  дают сигнал уже после факта.
- Данные берутся из REST API брокера с задержкой в единицы секунд — для
  внутридневной спекуляции на коротких таймфреймах этого может не хватать.

## Сборка

APK собирается в GitHub Actions workflow `build-tinvest-analyst-apk`
(артефакт `tinvest-analyst-debug-apk`) или локально в Android Studio:
JDK 17, compileSdk 34.
